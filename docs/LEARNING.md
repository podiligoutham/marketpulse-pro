# Learning Curriculum and Review Protocol

## Advanced React / TypeScript
Rendering and reconciliation; component composition; hooks and effect semantics; stale closures; controlled/uncontrolled state; concurrency and transitions; Suspense; data fetching and caching; routing; forms; accessibility; profiling; memoization; virtualization; chart rendering; WebSockets/SSE; state architecture; testing; TypeScript generics and discriminated unions.

## Advanced Java / Spring
JVM and memory; concurrency, executors, virtual threads where justified; collections and streams; immutability; Spring IoC/AOP/transactions; self-invocation; JPA performance and transaction boundaries; WebFlux versus MVC; API contracts; validation; security; caching; resilience; scheduling; Kafka semantics; PostgreSQL indexing/transactions; migrations; integration testing; observability.

## System design
Requirements and SLAs, load estimates, read scaling, caching, data freshness, idempotency, queueing, event delivery, consistency, failure modes, data partitioning, deployment patterns, cost and tradeoffs.

## AWS
IAM least privilege, VPC networking, S3/CloudFront, compute options, RDS economics, secrets, CloudWatch, CI/CD, budgets, security and incident response.

## Session routine
1. Explain the concept and why it matters.
2. Assign a task small enough to code independently.
3. Developer implements.
4. Review functionality, complexity, tests, UX, and security.
5. Ask interview-style follow-ups.
6. Record learning and next action in SESSION_LOG.

## Review bar
Be specific and demanding, not flattering. Distinguish must-fix defects from optional refinements. Never present fabricated test results.
